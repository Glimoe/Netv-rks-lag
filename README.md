# Netværks-lag

Byg og forstå en netværks-stack fra bunden: TCP, DNS, HTTP og HTTPS. Alt kører på loopback (127.0.0.1) i en hærdet Ubuntu Server-VM fra Linux 101-opgaven.

## Struktur

- [Modul 1: TCP](docs/01-tcp.md)
- Modul 2: DNS (kommer)
- Modul 3: HTTP (kommer)
- Modul 4: HTTPS/TLS (kommer)
- Modul 5: Integration (kommer)

Mapper: `docs/` (dokumentation), `src/` (kildekode), `evidence/` (screenshots og output pr. modul).

## Sådan køres koden (Modul 1)

```bash
python3 src/server.py    # terminal 1
python3 src/client.py    # terminal 2
```
